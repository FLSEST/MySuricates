Wishes & Factory

Von der Idee zum fertigen Workflow

💫 Wishes

„Ich brauche einen wöchentlichen Security-Report“
1. Decompose → Sub-Tasks identifizieren
2. Build → Workflow generieren
3. Verify → Pre-flight Check
4. Execute → Test-Run
5. Evaluate → Qualität prüfen
6. Iterate → Verbessern

🏭 Factory

Thema rein → Template raus
Generate: AI erstellt Workflow
Deploy: Auf Test-Instanz ausrollen
Test: Automatisch ausführen
Verify: Erfolg, Qualität, Kosten
Promote: Zum wiederverwendbaren Template

Multi-Provider: Claude + Codex
