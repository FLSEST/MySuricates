Kapitel 1: Einleitung

Willkommen zu diesem E-Book! Dieses Buch richtet sich an alle, die einen umfassenden Einstieg in die moderne Webentwicklung suchen. Wir behandeln die drei Grundpfeiler des Webs: HTML, CSS und JavaScript.

Die Webentwicklung hat sich in den letzten Jahren rasant weiterentwickelt. Neue Standards, Frameworks und Werkzeuge erscheinen in immer kuerzeren Abstaenden. Dieses Buch bietet eine solide Grundlage, auf der Sie aufbauen koennen.

Kapitel 2: Grundlagen der Webentwicklung

Bevor wir in die Details eintauchen, muessen wir verstehen, wie das Web funktioniert. Im Kern besteht jede Webseite aus einer Anfrage und einer Antwort zwischen Client und Server.

Wie das Web funktioniert

Der grundlegende Ablauf einer Webseitenanfrage sieht so aus:

  1. Der Benutzer gibt eine URL in den Browser ein
  2. Der Browser loest den Domainnamen ueber DNS auf
  3. Der Browser sendet eine HTTP-Anfrage an den Server
  4. Der Server verarbeitet die Anfrage und sendet eine Antwort
  5. Der Browser rendert die empfangenen Daten

Die drei Sauelen des Webs

Technologie Aufgabe Beispiel
HTML Struktur & Inhalt <h1>Titel</h1>
CSS Gestaltung & Layout color: blue;
JavaScript Verhalten & Interaktion alert('Hallo!');

HTTP-Statuscodes

Die wichtigsten HTTP-Statuscodes sollte jeder Webentwickler kennen:

  • 200 OK — Anfrage erfolgreich
  • 301 Moved Permanently — Ressource wurde dauerhaft verschoben
  • 404 Not Found — Ressource nicht gefunden
  • 500 Internal Server Error — Serverfehler

Ein einfacher HTTP-Request

GET /index.html HTTP/1.1
Host: www.beispiel.de
Accept: text/html
Accept-Language: de-DE

Kapitel 3: HTML im Detail

HTML (Hypertext Markup Language) bildet das Geruest jeder Webseite. Es definiert die Struktur und den semantischen Inhalt eines Dokuments.

Grundstruktur eines HTML-Dokuments

<!DOCTYPE html>
<html lang="de">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Meine Webseite</title>
</head>
<body>
  <header>
    <h1>Willkommen</h1>
    <nav>
      <a href="#ueber">Ueber uns</a>
      <a href="#kontakt">Kontakt</a>
    </nav>
  </header>
  <main>
    <p>Inhalt der Seite</p>
  </main>
  <footer>
    <p>&copy; 2026 Mein Unternehmen</p>
  </footer>
</body>
</html>

Semantische Elemente

HTML5 fuehrte zahlreiche semantische Elemente ein, die den Inhalt besser beschreiben:

  • <header> — Kopfbereich der Seite oder eines Abschnitts
  • <nav> — Navigationsbereich
  • <main> — Hauptinhalt der Seite
  • <article> — Eigenstaendiger Inhalt (z. B. Blogartikel)
  • <section> — Thematischer Abschnitt
  • <aside> — Ergaenzender Inhalt (Seitenleiste)
  • <footer> — Fussbereich

Formulare

Formulare sind das wichtigste Mittel fuer Benutzerinteraktion in HTML:

<form action="/anmeldung" method="POST">
  <label for="name">Name:</label>
  <input type="text" id="name" name="name" required>

  <label for="email">E-Mail:</label>
  <input type="email" id="email" name="email" required>

  <label for="nachricht">Nachricht:</label>
  <textarea id="nachricht" name="nachricht"></textarea>

  <button type="submit">Absenden</button>
</form>

Bilder und Medien

Bilder werden mit dem <img>-Element eingebunden. Fuer Barrierefreiheit ist das alt-Attribut unverzichtbar:

<img src="foto.jpg" alt="Beschreibung des Bildes" width="800" height="600">

<figure>
  <img src="diagramm.png" alt="Architektur-Diagramm">
  <figcaption>Abb. 1: Architektur der Webanwendung</figcaption>
</figure>

Naechstes Kapitel: CSS und Gestaltung

Kapitel 4: CSS und Gestaltung

CSS (Cascading Style Sheets) ist die Sprache, mit der wir das Aussehen unserer Webseiten gestalten. Von Farben ueber Schriften bis hin zu komplexen Layouts — CSS macht es moeglich.

Selektoren

CSS-Selektoren bestimmen, welche Elemente gestylt werden. Die wichtigsten Selektoren sind:

/* Element-Selektor */
p {
  color: #333;
}

/* Klassen-Selektor */
.hervorgehoben {
  background: yellow;
}

/* ID-Selektor */
#hauptnavigation {
  position: fixed;
  top: 0;
}

/* Kombinations-Selektor */
article > p:first-child {
  font-size: 1.2em;
  font-weight: bold;
}

Das Box-Modell

Jedes Element in CSS wird als Box behandelt. Das Box-Modell besteht aus vier Schichten:

  1. Content — Der eigentliche Inhalt
  2. Padding — Innenabstand
  3. Border — Rahmen
  4. Margin — Aussenabstand

Tipp: Setzen Sie box-sizing: border-box; auf alle Elemente, damit Padding und Border in die Gesamtbreite einberechnet werden.

Flexbox-Layout

Flexbox ist eines der maechtigsten Layout-Werkzeuge in CSS:

.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

.item {
  flex: 1;
  min-width: 200px;
}

CSS Grid

Fuer zweidimensionale Layouts eignet sich CSS Grid hervorragend:

.grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-gap: 2rem;
}

@media (max-width: 768px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

Responsive Design

Mit Media Queries passen wir das Layout an verschiedene Bildschirmgroessen an. Der wichtigste Grundsatz lautet: Mobile First.

Breakpoint Geraet Typische Breite
max-width: 480px Smartphone 320–480px
max-width: 768px Tablet 481–768px
max-width: 1024px Laptop 769–1024px
min-width: 1025px Desktop 1025px+

Kapitel 5: JavaScript-Grundlagen

JavaScript ist die Programmiersprache des Webs. Sie ermoeglicht Interaktivitaet, dynamische Inhalte und komplexe Anwendungen direkt im Browser.

Variablen und Datentypen

In modernem JavaScript verwenden wir const und let statt var:

// Konstante (unveraenderlich)
const PI = 3.14159;
const name = "Max Mustermann";

// Variable (veraenderlich)
let zaehler = 0;
let istAktiv = true;

// Datentypen
const text = "Hallo Welt";        // String
const zahl = 42;                   // Number
const wahr = true;                 // Boolean
const nichts = null;               // Null
const undefiniert = undefined;     // Undefined
const liste = [1, 2, 3];          // Array
const objekt = { name: "Max" };   // Object

Funktionen

JavaScript kennt verschiedene Arten, Funktionen zu definieren:

// Funktionsdeklaration
function addiere(a, b) {
  return a + b;
}

// Pfeilfunktion (Arrow Function)
const multipliziere = (a, b) => a * b;

// Funktion mit Standardparametern
function begruesse(name = "Welt") {
  return `Hallo, ${name}!`;
}

console.log(begruesse());          // "Hallo, Welt!"
console.log(begruesse("Max"));     // "Hallo, Max!"

DOM-Manipulation

JavaScript kann das HTML-Dokument dynamisch veraendern:

// Element finden
const titel = document.querySelector('h1');
const buttons = document.querySelectorAll('.btn');

// Inhalt aendern
titel.textContent = 'Neuer Titel';
titel.innerHTML = '<em>Kursiver</em> Titel';

// Event-Listener hinzufuegen
const button = document.querySelector('#meinButton');
button.addEventListener('click', (event) => {
  event.preventDefault();
  console.log('Button wurde geklickt!');
});

Fetch API

Mit der Fetch API koennen wir Daten von einem Server laden:

// Daten abrufen
async function ladeDaten() {
  try {
    const antwort = await fetch('https://api.beispiel.de/daten');
    if (!antwort.ok) {
      throw new Error(`HTTP-Fehler: ${antwort.status}`);
    }
    const daten = await antwort.json();
    console.log(daten);
  } catch (fehler) {
    console.error('Fehler beim Laden:', fehler);
  }
}

ladeDaten();

Kapitel 6: Werkzeuge und Workflow

Ein professioneller Entwicklungsworkflow erfordert die richtigen Werkzeuge. In diesem Kapitel stellen wir die wichtigsten vor.

Versionskontrolle mit Git

Git ist das Standardwerkzeug fuer Versionskontrolle in der Softwareentwicklung:

# Repository initialisieren
git init

# Dateien zum Staging hinzufuegen
git add index.html style.css

# Commit erstellen
git commit -m "Erste Version der Webseite"

# Branch erstellen und wechseln
git checkout -b feature/neues-design

# Aenderungen zusammenfuehren
git checkout main
git merge feature/neues-design

Paketmanager: npm

npm (Node Package Manager) verwaltet Abhaengigkeiten in JavaScript-Projekten:

# Projekt initialisieren
npm init -y

# Paket installieren
npm install lodash

# Entwicklungsabhaengigkeit installieren
npm install --save-dev eslint

# Skript ausfuehren
npm run build

Build-Werkzeuge

Moderne Webprojekte nutzen Build-Werkzeuge fuer Optimierung und Transformation:

  • Vite — Schneller Entwicklungsserver und Bundler
  • Webpack — Konfigurierbarer Module-Bundler
  • ESLint — Code-Qualitaet und Stilrichtlinien
  • Prettier — Automatische Code-Formatierung

Browser DevTools

Die Entwicklerwerkzeuge im Browser sind unverzichtbar fuer das Debugging:

Tab Funktion Tastenkuerzel
Elements HTML/CSS inspizieren Strg+Umschalt+C
Console JavaScript-Konsole Strg+Umschalt+J
Network Netzwerk-Anfragen Strg+Umschalt+E
Sources Quellcode debuggen Strg+Umschalt+S

Kapitel 7: Best Practices und Muster

Guter Code zeichnet sich nicht nur durch Funktionalitaet aus, sondern auch durch Lesbarkeit, Wartbarkeit und Skalierbarkeit. In diesem Kapitel sammeln wir die wichtigsten Best Practices.

Code-Organisation

Eine saubere Projektstruktur ist die Grundlage fuer jedes Projekt:

projekt/
  ├── index.html
  ├── css/
  │   ├── reset.css
  │   ├── variables.css
  │   └── main.css
  ├── js/
  │   ├── app.js
  │   ├── utils.js
  │   └── components/
  │       ├── navigation.js
  │       └── modal.js
  ├── assets/
  │   ├── images/
  │   └── fonts/
  └── README.md

Barrierefreiheit (Accessibility)

Barrierefreiheit ist kein optionales Feature, sondern eine Grundanforderung. Die wichtigsten Regeln:

  1. Verwenden Sie semantisches HTML (nicht alles ist ein <div>)
  2. Stellen Sie ausreichenden Farbkontrast sicher (mind. 4.5:1)
  3. Alle Bilder brauchen Alt-Texte
  4. Die Seite muss per Tastatur bedienbar sein
  5. Verwenden Sie ARIA-Attribute wo noetig
<!-- Schlecht -->
<div class="btn" onclick="absenden()">Absenden</div>

<!-- Gut -->
<button type="submit" aria-label="Formular absenden">
  Absenden
</button>

Performance-Optimierung

Schnelle Ladezeiten sind entscheidend fuer die Benutzererfahrung:

  • Bilder optimieren — WebP-Format, responsive Bilder mit srcset
  • CSS/JS minimieren — Unnoetige Zeichen entfernen
  • Lazy Loading — Bilder erst laden, wenn sie sichtbar werden
  • Caching — Browser-Cache effektiv nutzen
  • Code-Splitting — Nur laden, was benoetigt wird

Faustregel: Eine Webseite sollte in weniger als 3 Sekunden vollstaendig geladen sein. Jede weitere Sekunde kostet im Durchschnitt 7% der Konversionsrate.

Sicherheit

Grundlegende Sicherheitsmassnahmen fuer Webanwendungen:

  • XSS verhindern — Benutzereingaben immer escapen
  • CSRF-Token — Formulare gegen Faelschung schuetzen
  • HTTPS — Verschluesselte Verbindungen erzwingen
  • Content Security Policy — Erlaubte Ressourcen einschraenken
