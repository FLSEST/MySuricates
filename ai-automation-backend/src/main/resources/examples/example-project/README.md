# Example project · Beispielprojekt

**English.** This directory belongs to the example project that MySuricates creates on request. It is a
copy of a template shipped with MySuricates, so you can change or delete anything in it. The example
workflows of this project need no AI. Apart from the done TODO of the TODO example, they leave nothing
behind outside their own run.

To work on your own files, create a project of your own and point it at your directory. Every template
and every example can be added to any project.

To start over, delete this directory and create the example project again.

---

**Deutsch.** Dieses Verzeichnis gehört zum Beispielprojekt, das MySuricates auf Wunsch anlegt. Es ist
eine Kopie einer mitgelieferten Vorlage, du darfst also alles darin ändern oder löschen. Die
Beispiel-Workflows dieses Projekts kommen ohne KI aus. Außer dem erledigten TODO des TODO-Beispiels
hinterlassen sie nichts außerhalb ihres eigenen Laufs.

Für deine eigenen Dateien legst du ein eigenes Projekt an und gibst dein Verzeichnis an. Jede Vorlage
und jedes Beispiel lässt sich in jedes Projekt übernehmen.

Neu anfangen: dieses Verzeichnis löschen und das Beispielprojekt erneut anlegen.
