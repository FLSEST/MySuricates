Gesamtzusammenfassung

Clean Code: A Handbook of Agile Software Craftsmanship von Robert C. Martin (erschienen 2008) ist eines der einflussreichsten Buecher der Softwareentwicklung. Es lehrt Entwickler, Code zu schreiben, der nicht nur funktioniert, sondern auch lesbar, wartbar und elegant ist.

Das Buch gliedert sich in drei Teile: Im ersten Teil werden die Prinzipien, Muster und Praktiken des sauberen Codes vorgestellt. Der zweite Teil enthaelt Fallstudien zunehmender Komplexitaet. Der dritte Teil destilliert die Erkenntnisse in eine Sammlung von Heuristiken und Code-Geruechen.
